# kitty vpn

**версия: 1.0.8**

telegram-бот для управления vpn-подписками через 3x-ui.

## возможности

### для пользователя

- `/start` — главное меню или trial для нового пользователя.
- `🎁 начать trial` — тестовый доступ на `TRIAL_HOURS` часов.
- `🔗 подписка` — json-подписка, срок действия и устройства.
- `📱 устройства` — просмотр hwid и удаление устройств.
- `🎟 промокод` — применение промокода для продления.
- `💳 купить / продлить` — тариф и связь с администратором.
- `🆘 поддержка` — переход в тикет-систему.
- `ℹ️ о сервисе` — документы сервиса.

### промокоды

администратор создаёт промокод формата `код дни лимит`. лимит `0` означает неограниченное количество использований.
один telegram-пользователь может применить конкретный промокод только один раз.

## админ-панель

открывается командой `/kittyadmin` и доступна только `ADMIN_ID`.

- привязка подписки: `telegram_id sub_id`;
- продление: `sub_id дни`, количество дней задаётся вручную;
- создание промокода: `код дни лимит`;
- действия с пользователем: продление и бан по `sub_id`.

## подписки

используется только json-формат: `https://87.121.82.175:2096/jsnn/<sub_id>`.

клиент создаётся с inbound: 8 🇫🇮, 20 🇸🇪, 30 🇩🇪, 31 🇵🇱.

## структура проекта

- `bot.py` — telegram-интерфейс и логика бота.
- `db.py` — sqlite-слой, пользователи и промокоды.
- `xui.py` — работа с api 3x-ui.
- `config.py` — настройки и env.
- `requirements.txt` — зависимости.

## база данных

`users` хранит telegram id, username, email, sub id, url, статус и срок действия.
`promo_codes` хранит промокоды, награду, лимит, счётчик, срок действия и состояние.
`promo_uses` хранит факты использования промокодов.

## конфигурация

обязательные переменные: `BOT_TOKEN`, `ADMIN_ID`, `XUI_API_TOKEN`.

по умолчанию:
- `XUI_HOST=https://127.0.0.1:1337/ZoxJbyRPdLe5t4y243`
- `TRIAL_HOURS=12`
- `TRIAL_LIMIT=4`
- `DATABASE_PATH=/opt/vpn-bot/bot.db`

секреты не коммитить.

## окружение

- python 3.12+
- aiogram 3.x
- aiosqlite
- python-dotenv
- aiohttp
- apscheduler

после обновления:
```bash
cd /opt/vpn-bot
python3 -m py_compile bot.py db.py
systemctl restart vpn-bot
```
