# kitty vpn

**версия: 1.0.9**

telegram-бот для управления vpn-подписками через 3x-ui.

## возможности

### пользователь

- `/start` — главное меню или trial.
- `🎁 начать trial` — тестовый доступ.
- `🔗 подписка` — json-подписка, срок и устройства.
- `📱 устройства` — просмотр hwid и удаление устройств.
- `🎟 промокод` — применение промокода.
- `💳 купить / продлить` — тариф и связь с администратором.
- `🆘 поддержка` — тикет-система.
- `ℹ️ о сервисе` — документы.

## кастомизация

через `/kittyadmin` → `🎨 кастомизация` администратор может настраивать главное меню и меню подписки.

для обоих меню доступны:
- изменение верхнего текста;
- установка фото;
- удаление фото;
- переименование кнопок;
- возврат стандартного текста;
- предпросмотр.

переименование меняет только отображаемый текст: действия и `callback_data` кнопок сохраняются.

фотографии хранятся как telegram `file_id`, поэтому настройки переживают перезапуск бота.

## админ-панель

`/kittyadmin` доступна только `ADMIN_ID`.

- привязка подписки;
- продление через `sub_id дни`;
- создание промокода;
- действия с пользователем;
- кастомизация интерфейса.

## база данных

используются таблицы:
- `users`;
- `promo_codes`;
- `promo_uses`;
- `bot_settings`.

`bot_settings` хранит тексты, названия кнопок и file id фотографий. существующая sqlite-база автоматически мигрируется.

## конфигурация

обязательные переменные:
- `BOT_TOKEN`;
- `ADMIN_ID`;
- `XUI_API_TOKEN`.

по умолчанию:
- `TRIAL_HOURS=12`;
- `TRIAL_LIMIT=4`;
- `DATABASE_PATH=/opt/vpn-bot/bot.db`.

секреты не коммитить.

## окружение

- python 3.12+
- aiogram 3.x
- aiosqlite
- python-dotenv
- aiohttp
- apscheduler

после обновления:

```bash
cd /opt/vpn-bot
python3 -m py_compile bot.py db.py
systemctl restart vpn-bot
```

## релиз

актуальная версия: **1.0.9**.

перед изменениями использовать актуальный `bot.py` из github и сохранять совместимость с текущей sqlite-базой.
