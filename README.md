# kitty vpn

**версия: 1.1**

telegram-бот для управления vpn-подписками через 3x-ui с автоматической оплатой через rollypay.

## возможности

### пользователь

- `/start` — главное меню или trial.
- `🎁 начать trial` — тестовый доступ.
- `🔗 подписка` — просмотр подписки, срока и лимита устройств.
- `📱 устройства` — просмотр подключённых hwid и удаление устройств.
- `🎟 промокод` — применение промокода.
- `💳 купить / продлить` — выбор количества устройств и срока, создание платежа.
- `🆘 поддержка` — переход в тикет-систему.
- `ℹ️ о сервисе` — документы сервиса.

### тарифы

- от 3 до 10 устройств;
- 3 устройства — 80 ₽ / месяц;
- каждое дополнительное устройство — +50 ₽ / месяц;
- доступен срок 1 или 3 месяца;
- для 3 месяцев применяется скидка.

после успешной оплаты подписка автоматически продлевается, а выбранный лимит устройств устанавливается в 3x-ui.

## оплата

для платежей используется rollypay.

бот:
1. создаёт платёж;
2. сохраняет его параметры в sqlite;
3. отправляет пользователю ссылку на оплату;
4. получает webhook после оплаты;
5. проверяет подпись, сумму, валюту и test-режим;
6. автоматически продлевает подписку.

повторная обработка уже оплаченного платежа не выполняется.

webhook работает отдельным сервисом и не занимает порт панели 3x-ui.

## админ-панель

`/kittyadmin` доступна только `ADMIN_ID`.

- привязка подписки;
- продление через `sub_id дни`;
- создание промокода;
- действия с пользователем;
- включение и выключение технических работ;
- изменение сообщения технических работ.

при включённых технических работах обычным пользователям доступен только экран с сообщением о недоступности бота. администратор сохраняет полный доступ.

## база данных

используются таблицы:

- `users`;
- `promo_codes`;
- `promo_uses`;
- `payments`;
- `bot_settings`.

таблица `payments` хранит payment id, order id, telegram id, сумму, валюту, срок, test-режим, лимит устройств, количество месяцев и статус платежа.

существующая sqlite-база автоматически мигрируется при запуске.

## конфигурация

обязательные переменные:

- `BOT_TOKEN`;
- `ADMIN_ID`;
- `XUI_API_TOKEN`.

для rollypay:

- `ROLLYPAY_API_KEY`;
- `ROLLYPAY_SIGNING_SECRET`;
- `ROLLYPAY_CALLBACK_URL`;
- `ROLLYPAY_TEST`;
- `ROLLYPAY_DEFAULT_PRICE`;
- `ROLLYPAY_DEFAULT_DAYS`.

по умолчанию:

- `TRIAL_HOURS=12`;
- `TRIAL_LIMIT=4`;
- `ROLLYPAY_TEST=true`;
- `ROLLYPAY_DEFAULT_PRICE=80`;
- `ROLLYPAY_DEFAULT_DAYS=30`;
- `DATABASE_PATH=/opt/vpn-bot/bot.db`.

секреты не коммитить.

## окружение

- python 3.12+
- aiogram 3.x
- aiosqlite
- python-dotenv
- aiohttp
- apscheduler

после обновления:

```bash
cd /opt/vpn-bot
python3 -m py_compile bot.py db.py
systemctl restart vpn-bot
```

для обновления из github:

```bash
cd /opt/vpn-bot
git pull
systemctl restart vpn-bot
```
